    Invoice backup (India)

    {{ pill[1] }}

    Indian tax law (Income-tax Rules 2026, rule 46(8)) needs a daily backup of the books on servers in India. Once a day the worker service uploads every paid order as a CSV to the INVOICE_BACKUP_BUCKET bucket. {% if backup.state == 'off' %}It starts when INVOICE_BACKUP_BUCKET, INVOICE_BACKUP_ACCESS_KEY_ID and INVOICE_BACKUP_SECRET_ACCESS_KEY are set on the worker service (Configuration below shows this web service only). {% endif %}Each file holds every paid order still inside the 8-year record period. Before each upload the worker checks that a lifecycle rule on the bucket deletes files under invoices/ within 90 days (keep bucket versioning off), and it never replaces a file already stored. Refunds are made in the payment provider and are not in this file, so keep the provider's refund reports with your books in India too. The download is the same file, for the accountant.
