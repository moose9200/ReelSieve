Account recovery

Forgot your password?

BNBsieve is self-hosted and doesn't send email, so recovery is done by whoever runs the server.

  1. Another admin can sign in and set a new password for you in Settings → Users.
  2. Server owner: set the environment variables APP_USER (your email) and APP_PASSWORD on the host (Railway → Variables, or .env.local locally), restart, sign in, then change your password in Settings and remove the variables.
